# RS.GE Tax Agent — Автоматизация налоговых деклараций ИП в Грузии

[![CI](https://github.com/Morgunov-Vitaly/rs-ge-agent/actions/workflows/ci.yml/badge.svg)](https://github.com/Morgunov-Vitaly/rs-ge-agent/actions/workflows/ci.yml)

Экспериментальный self-hosted агент для учета доходов, проверки данных RS.GE и подготовки автоматизации налоговых деклараций индивидуального предпринимателя в Грузии.

Управление осуществляется через **Telegram-бота** в полуавтоматическом режиме (*Human-in-the-Loop*). Текущая версия умеет вести журнал, входить на RS.GE, читать существующий черновик и сверять платежи. Создание и финальная отправка декларации пока не реализованы.

> Проект находится на стадии персонального MVP и не заменяет проверку бухгалтера. Актуальное направление продукта и границы функций описаны в [Product & Architecture RFC](docs/PRODUCT_ARCHITECTURE_RFC.md).

---

## 🚀 Основные возможности

1. **Telegram-интерфейс**:
   - Быстрый ввод доходов вручную (`15.10 3200 USD` или `5000 GEL`).
   - Загрузка выписок TBC/Bank of Georgia — запланирована, пока не реализована.
   - Запрос 2FA SMS-кода прямо в чате бота при авторизации на `rs.ge`.
   - Просмотр и сверка существующего черновика декларации по скриншоту.
   - Ссылка и реквизиты на быструю оплату налога (`/pay`).
   - Сверка истории платежей в личной карточке RS.GE с датами и суммами из Google Sheets (`/payments`).
   - Проверка статуса поданных деклараций (`/status`).

2. **Официальные курсы валют Нацбанка Грузии (NBG)**:
   - Интеграция с открытым API NBG.
   - Автоматический расчет эквивалента в лари (GEL) на **дату фактического поступления средств** в соответствии с налоговым кодексом Грузии.

3. **Синхронизация с Google Таблицами**:
   - Автоматическое ведение журнала учета доходов.
   - Проверка дубликатов транзакций.
   - Хранение сумм, дат, курсов и статусов деклараций по месяцам.

4. **Умный контроль календаря (Smart Schedule Guard)**:
   - Блокировка попыток подачи декларации раньше наступления следующего месяца.
   - Предупреждение о датах автозаполнения (на `rs.ge` автозаполнение нарастающего итога включается после 5 числа).
   - Напоминания о дедлайне 15-го числа.

5. **Браузерная автоматизация (Playwright)**:
   - Headless-браузер в изолированном Docker-контейнере.
   - Вход в личный кабинет `eservices.rs.ge`.
   - Навигация по модулям `decl.rs.ge`.
   - Просмотр существующего черновика малого бизнеса и проверка граф 15, 20 и 26. Создание и отправка формы запланированы.

## 🛠️ Стек технологий

- **Среда выполнения**: Node.js (версия 20+), Docker, Docker Compose.
- **Браузерная автоматизация**: Playwright (Chromium Headless).
- **Мессенджер-интерфейс**: Telegram Bot API (`telegraf`).
- **Внешние API**:
  - Открытый API Национального банка Грузии (`nbg.gov.ge`).
  - Google Sheets API (`googleapis`).
  - Портал Налоговой службы Грузии (`eservices.rs.ge` / `decl.rs.ge`).

### Архитектурные слои

- `domain/` — налоговые правила и общие типы без зависимостей от интерфейсов;
- `workflows/` — прикладные сценарии сверки и проверки;
- `connectors/` — адаптеры Google Sheets и RS.GE;
- `modules/` — manifest доступных услуг и классов риска;
- `infrastructure/` — обезличенный JSONL audit log;
- `services/bot.js` — Telegram-интерфейс и Human-in-the-Loop SMS.

Текущие действия модуля малого бизнеса имеют риск `READ_ONLY`. Будущие изменения черновиков, отправки и платежные действия должны требовать отдельного подтверждения.

Критичные селекторы RS.GE проверяются браузерными контрактными тестами на обезличенных HTML-фикстурах. Они не обращаются к реальному аккаунту и не содержат персональных данных.

## 📋 Быстрый старт

### 1. Настройка переменных окружения

Скопируйте пример конфигурации и заполните данные:

```bash
cp .env.example .env
```

Отредактируйте `.env`:
```env
# Доступ к личному кабинету rs.ge
RS_USERNAME=ваш_логин_или_инн
RS_PASSWORD=ваш_пароль

# Telegram бот
TELEGRAM_BOT_TOKEN=токен_от_BotFather
TELEGRAM_CHAT_ID=ваш_личный_chat_id

# Google Sheets
GOOGLE_SPREADSHEET_ID=id_вашей_таблицы
GOOGLE_CREDENTIALS_PATH=./google-credentials.json

# Необязательные пути runtime
RS_SESSION_STORAGE_PATH=./session_state.json
RS_SCREENSHOTS_DIR=./screenshots
AUDIT_LOG_PATH=./logs/audit.jsonl
```

### 2. Запуск через Docker Compose

Сборка и запуск контейнера:

```bash
# Сборка контейнера
docker compose build

# Запуск в интерактивном режиме
docker compose run --rm agent
```

## 📖 Команды Telegram-бота

- `/start` — Главное меню и краткая справка.
- `/status` — Текущий статус за отчетный месяц (доход в GEL, налог 1%, статус декларации).
- `/fill` — Вход на `rs.ge`, открытие существующего черновика и сверка с Google Sheets. Создание/отправка пока не выполняются.
- `/pay` — Получение ссылки на оплату и реквизитов Казначейства.
- `/payments` — Read-only сверка фактических платежей на `rs.ge` с колонкой «Дата оплаты» и налогом в Google Sheets. Команда показывает округления, расхождения дат/сумм и не изменяет таблицу автоматически.
- Отправка текста вида `15.10 2500 USD` — автоматический пересчет по курсу NBG на указанную дату и запись в журнал.
