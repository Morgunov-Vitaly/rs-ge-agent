# Licensing model

## Community license

RS.GE Tax Agent is distributed under `AGPL-3.0-only`. The complete license text is in [LICENSE](LICENSE).

The community license permits personal and commercial use, modification, distribution, paid hosting and support, subject to its conditions. In particular, a modified version that users interact with over a network must offer those users access to its corresponding source code as required by section 13 of the AGPL.

Credentials, taxpayer data, declarations, bank records, private configuration and other user data are not source code and must never be published with the project.

Third-party dependencies retain their own licenses. The AGPL designation in this repository does not replace or override those licenses.

## Commercial licensing

Copyright holders may separately offer the same code under commercial terms, for example when an organization wants to include it in a proprietary product without using the AGPL option.

No commercial license is currently published or granted automatically. A commercial agreement, price, warranty, support level and permitted use must be negotiated separately with the copyright holder.

Using the public repository does not imply a commercial license, product warranty, official affiliation with the Revenue Service of Georgia, or permission to use third-party trademarks.

## Contributions

Dual licensing remains practical only when the project has the necessary rights to license all accepted contributions. The draft [CLA.md](CLA.md) therefore needs to be activated before substantial external contributions are accepted.

Activating it requires:

1. identifying the individual or legal entity that will act as the project licensor;
2. legal review of the contributor agreement for the relevant jurisdictions;
3. documenting an auditable acceptance mechanism for pull requests;
4. retaining a record of every contributor's acceptance.

Until that process is active, maintainers should not merge substantial third-party code intended for later commercial relicensing.
